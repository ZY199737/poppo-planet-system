# 荣誉消息通知 & 荣誉分享 — 复盘数据报表设计

## 报表用途
功能上线后，供产品/运营团队定期复盘，评估荣誉消息的触达效果、用户互动意愿、分享传播能力和拉新转化价值。

---

## 六、新老版本对比

对比有分享功能的新版本 vs 只有保存功能的老版本用户行为差异：

| 指标 | 新版本用户 | 老版本用户 | 差异 |
|------|------------|------------|------|
| 用户数 | 89,230 | 36,200 | — |
| 消息打开率 | 36.2% | 31.0% | +5.2pp |
| 卡片查看率 | 80.1% | 74.3% | +5.8pp |
| 海报生成率 | 47.8% | 39.5% | +8.3pp |
| 保存到相册 | 68.2% | 85.1% | -16.9pp |
| 触发分享 | 54.9% | — | 新增功能 |
| 分享成功 | 84.0% | — | 新增功能 |

> 老版本仅有「保存到相册」按钮，无分享功能。新版本保存率下降是因为部分用户转向了分享操作。

## 八、报表筛选维度

所有板块均支持以下筛选条件联动：

| 筛选项 | 可选值 |
|--------|--------|
| 日期范围 | 自定义起止日期 |
| 荣誉大类 | 全部 / 勋章荣誉 / 主播等级荣誉 / 用户荣誉 |
| 荣誉小类 | 全部 / 直播之星 / 随机PK / 亲密度 / 活跃之星 / 时薪升级 / 时薪周报 / SVIP / 王者守护 |
| 荣誉等级 | 全部 / 具体等级（如 Lv3-Lv10） |
| 平台 | 全部 / iOS / Android |
| 客户端版本 | 全部 / 新版本（有分享） / 老版本（仅保存） |
