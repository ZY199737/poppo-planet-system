建设者等级体系规划

PRD

一、背景与目标

1.1 现状

建设者中心一期已上线，仅开放「翻译查错」场景，验证了"用户提交建议 → 人工审核 → 平台奖励"的核心闭环。当前问题：激励为单次金币，无成长体系；身份无差异，无竞争目标；贡献不可见，无荣誉感。

1.2 目标

将建设者中心改造为「Poppo 宇宙」世界观——用户不是在做任务，而是在建设属于自己的星球。通过星球分类、等级成长、排行竞争、领主荣誉，驱动用户持续参与。

二、星球首页

首页为星球宇宙的主入口，以星座连线布局展示所有星球，营造太空探索氛围。

2.3 星球通告

首页底部的任务推荐模块，展示各星球当前可参与的推荐任务，每条显示星球标签、任务名称、奖励预览。点击可直接跳转对应星球详情页。

三、星球详情页

点击已开放的星球进入详情页，结构统一：星球视觉 → 等级卡片 → 可参与任务 → 本月排行榜。

3.1 共创星详情

▶ 查看共创星详情

  • 星球视觉：紫色星球 + 世界观描述"声音汇聚之地，每位建设者的建议都在塑造 Poppo 的未来"
  • 等级卡片：显示当前等级（如 T1 体验官）、能量进度条（120/200）、距升级所需能量；点击进入等级详情页
  • 可参与任务：翻译查错 — 被采纳 +30 能量 · 1000 金币/条
  • 本月排行：展示 Top10 用户，第一名带👑领主标识

3.2 传播星详情

▶ 查看传播星详情

  • 星球视觉：橙色星球 + 世界观描述"光芒扩散的起点，传播者让更多人看到 Poppo 的精彩"
  • 等级卡片：显示当前等级（如 T1 传播新手）、能量进度条（95/200）；点击进入等级详情页
  • 可参与任务：站外扩散 — 合格 +30 能量 · 优质 +50 能量
  • 本月排行：新星球暂无数据时显示"快来冲榜吧！"空态

3.3 守护星详情

▶ 查看守护星详情

  • 星球视觉：绿色星球 + 世界观描述"秩序守护的堡垒，守护者公正裁决维护社区的健康环境"
  • 等级卡片：显示当前等级（如 T1 见习守护）、能量进度条（80/200）；点击进入等级详情页
  • 可参与任务：举报投诉评判、举报PK — 被采纳 +30 能量 · 1000 金币/条

五、排行与荣誉

5.1 星球领主

  • 每月能量排名第1名获封"星球领主"，在星球首页和详情页展示头像+昵称+👑标识
  • 每月1日0:00重置，统计自然月内能量获取总量
  • 权益：领主专属称号、头像框、额外金币奖励

5.2 星球护卫

  • 月末排名第2-10名获封"星球护卫"
  • 权益：护卫称号、专属头像框、额外金币奖励

关于贡献值

什么是贡献值？

贡献值是你在星球中完成任务、参与互动获得的能量累计，代表你对星球的贡献程度。

如何获得贡献值？

  • 完成每日任务和挑战任务
  • 参与星球互动活动
  • 邀请好友加入星球

贡献值的作用

贡献值决定你在榜单中的排名，排名越高可获得更多专属奖励和特权。
