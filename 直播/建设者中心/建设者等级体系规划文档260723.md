# 建设者等级体系规划文档

## 一、背景与目标

### 1.1 现状

建设者中心一期已上线，当前状态：
- 仅开放「翻译查错」一个场景，验证了"用户提交建议 → 人工审核 → 积分奖励"的核心闭环
- 激励方式为单次金币奖励（1000金币/条被采纳建议），无累积性成长机制
- 用户身份仅区分"普通用户"和"建设者"（完成培训即获得），无层级差异
- 后续计划扩展的应用场景包括：站内外宣传、优质主播发掘、投诉评判、iOS好评、用户调研、品牌周边宣传、单投PK、新功能体验

### 1.2 问题

| 问题 | 影响 |
|------|------|
| 缺乏成长感 | 用户完成任务后只拿金币，没有持续参与的动力；做完一次就流失 |
| 身份无差异 | 所有建设者身份等同，活跃用户和低活跃用户无区分，无竞争和追逐目标 |
| 贡献不可见 | 用户的累积贡献没有展示位，无法形成社交货币和荣誉感 |
| 激励单一 | 仅有金币，缺乏精神激励（称号、徽章、特权），对非物质驱动型用户吸引力不足 |
| 缺乏趣味性 | 纯任务列表模式，用户无代入感，感觉是在"打工"而非"参与建设" |

### 1.3 目标

将建设者中心改造为**「Poppo 宇宙」**世界观——用户不是在做任务，而是在**建设属于自己的星球**：

1. **世界观代入感**：不同场景归类为不同"星球"，用户在对应星球上贡献力量，感知自己在建设 Poppo 的世界
2. **集体建设可视化**：每个星球有"繁荣度"，所有用户的贡献汇聚后让星球从荒芜逐渐走向繁荣，视觉状态随之变化
3. **星球独立成长**：每个星球有独立的称号体系，用户在不同星球可拥有不同身份等级
4. **竞争与荣誉**：每月每个星球产生一位"星球领主"，作为最高荣誉展示
5. **物质+精神并重**：金币奖励之外，称号、领主荣誉、星球视觉变化提供精神层面的满足

- 建设者中心一期 PRD：[直播-其他-建设者中心体系260706](https://uf1iawhques.sg.larksuite.com/wiki/UQbfw3iYUisXSRkgW2JlmrrwgCh)

## 二、星球体系设计

### 2.1 星球划分

Poppo 宇宙包含 5 颗星球，每颗星球对应一类建设场景，星球命名与场景高度关联：

| 星球 | 主题 | 包含场景 | 世界观设定 |
|------|------|----------|-----------|
| 译言星 | 语言与沟通 | 翻译查错 | 曾经语言混乱的星球，建设者修复文字秩序，让居民重新理解彼此 |
| 星耀星 | 传播与声量 | 站内外宣传、品牌周边宣传、iOS好评、单投PK | Poppo之光需要传播者，让更多人看到这个世界的精彩 |
| 瞭望星 | 发现与探索 | 优质主播发掘 | 宇宙中隐藏着无数宝藏，瞭望者负责发现那些被埋没的闪光点 |
| 天秤星 | 秩序与公正 | 投诉评判 | 宇宙的秩序需要守护，天秤守卫者裁定纷争、维护正义 |
| 灵感星 | 进化与创新 | 用户调研、新功能体验 | 收集智慧结晶的星球，每一份反馈都在推动 Poppo 宇宙的进化 |

### 2.2 星球称号体系

每个星球有 **4 级独立称号**，用户在对应星球上积累贡献即可晋升。不同星球的称号名称各不相同，贴合其世界观主题：

| 等级 | 译言星 | 星耀星 | 瞭望星 | 天秤星 | 灵感星 |
|------|--------|--------|--------|--------|--------|
| T1（入门） | 见习译者 | 星光学徒 | 初级探员 | 见习裁判 | 灵感收集者 |
| T2（进阶） | 文字工匠 | 光芒使者 | 星际猎手 | 秩序守卫 | 创意炼金师 |
| T3（精通） | 译言大师 | 星耀先锋 | 首席瞭望官 | 天秤执裁官 | 进化引导者 |
| T4（传奇） | 译言宗师 | 星耀之王 | 宇宙探险家 | 正义天秤 | 灵感贤者 |

**晋升规则：**

| 等级 | 能量值区间 | 定位 |
|------|-----------|------|
| T1 | 0 - 199 | 刚接触该星球，完成新手引导 |
| T2 | 200 - 999 | 稳定贡献，成为该星球的常驻建设者 |
| T3 | 1,000 - 2,999 | 深度参与，质量突出 |
| T4 | 3,000+ | 该星球的传奇建设者，长期核心贡献 |

**设计考量：**
- T1→T2 门槛低，保证新用户快速获得升级正反馈
- T3→T4 为荣誉等级，代表在该领域的深度积累
- 各星球等级完全独立，用户可以是译言星 T4 + 天秤星 T1

### 2.3 星球能量值

"星球能量"是衡量用户对单个星球贡献的计量单位，替代传统的"经验值"概念。

#### 2.3.1 能量获取规则

| 行为类型 | 能量值 | 说明 |
|----------|--------|------|
| 建议/成果被采纳 | +30 | 核心产出行为，权重最高 |
| 提交贡献（不论结果） | +5 | 鼓励参与，即使未采纳也有积累 |
| 重复/无效提交 | +0 | 不奖励水分 |
| 连续7天在同一星球贡献 | +50（额外） | 鼓励持续深耕 |
| 单月该星球采纳≥10条 | +100（额外） | 月度里程碑 |
| 首次登陆新星球（首次提交） | +20 | 鼓励探索更多星球 |

#### 2.3.2 能量衰减

| 规则 | 说明 |
|------|------|
| 触发条件 | 连续 30 天未在该星球有任何有效提交 |
| 衰减速度 | 每周衰减当前能量值的 2% |
| 保底 | 不低于当前称号等级下限（不会因衰减降超过 1 级） |
| 违规扣除 | 恶意灌水/作弊，单次扣除 100 能量值，累计 3 次冻结该星球权限 |

### 2.4 星球领主

每个星球每月产生一位**星球领主**——当月对该星球贡献最多的建设者。

**机制：**
- 每月 1 日 0:00 重置，统计自然月内该星球的能量值获取总量
- 月末结算时，排名第一者获封"星球领主"
- 一个用户可同时担任多个星球的领主（足够活跃的话）
- 领主荣誉持续展示至下月结算（即展示整个次月）

**领主权益：**
- 专属"领主"称号（在原有称号上叠加光效/皇冠标识）
- 星球页面顶部领主展示位（头像+昵称+贡献值）
- 领主专属头像框（当月有效）
- 额外金币奖励（月度结算时一次性发放）

### 2.5 星球繁荣度

繁荣度是**全体建设者贡献的集体指标**，体现"我们一起建设了这个星球"的感知。

**计算方式：**
- 繁荣度 = 该星球所有用户当月累计能量值总和
- 按自然月重置，每月从 0 开始积累

**繁荣度阶段与视觉变化：**

| 阶段 | 繁荣度区间 | 星球视觉状态 | 描述 |
|------|-----------|-------------|------|
| 荒芜期 | 0 - 999 | 灰暗、破碎 | 星球刚被发现，一片荒芜 |
| 萌芽期 | 1,000 - 4,999 | 出现绿意/光点 | 建设者开始注入生命力 |
| 发展期 | 5,000 - 14,999 | 色彩丰富、有建筑轮廓 | 文明初现 |
| 繁荣期 | 15,000 - 29,999 | 生机勃勃、城市灯火 | 星球欣欣向荣 |
| 辉煌期 | 30,000+ | 华丽满级状态、光环环绕 | 星球达到巅峰文明 |

**设计要点：**
- 每个星球的视觉风格贴合其主题（如译言星有文字元素，天秤星有天秤/法典元素）
- 繁荣度变化时全体建设者收到通知："译言星进入繁荣期！感谢每位建设者的贡献"
- 用户在星球页面能看到当前繁荣度进度条和当月全体贡献值

## 三、权益体系

### 3.1 称号权益（按星球等级）

| 等级 | 物质权益 | 精神权益 |
|------|----------|----------|
| T1 | 被采纳获 1000 金币/条 | 对应星球基础身份标签 |
| T2 | 被采纳获 1200 金币/条 | 星球专属称号展示；星球等级图标 |
| T3 | 被采纳获 1500 金币/条；每月额外 500 金币 | 星球专属头像框；贡献履历展示位 |
| T4 | 被采纳获 2000 金币/条；每月额外 1000 金币 | 限定称号+进场特效；提案通道（可建议星球玩法改进） |

### 3.2 领主权益（月度）

| 权益 | 说明 |
|------|------|
| 领主称号 | 在原称号上叠加"XX星领主"标识，全站可见 |
| 星球页展示 | 星球主页顶部C位展示，持续一个月 |
| 专属头像框 | 领主限定头像框（次月自动回收） |
| 金币奖励 | 月度结算时一次性发放 3000 金币 |
| 领主发言 | 可在星球页发布一条"领主寄语"，所有该星球建设者可见 |

### 3.3 跨星球成就（探索激励）

为鼓励用户探索多个星球，设置跨星球成就：

| 成就 | 条件 | 奖励 |
|------|------|------|
| 星际旅行者 | 在 3 个星球达到 T1 | 专属徽章 + 500 金币 |
| 宇宙建筑师 | 在 3 个星球达到 T2 | 限定头像框 + 1000 金币 |
| 全能领主 | 同时担任 2 个星球的领主 | 专属称号"双星领主" + 限定特效 |
| 宇宙霸主 | 同时担任 3 个及以上星球的领主 | 全站唯一称号"宇宙霸主" + 季度实物礼包 |

## 四、核心功能模块

### 4.1 Poppo 宇宙主页

建设者中心改造为"宇宙地图"视觉，入口展示所有星球的概览：

**展示内容：**
- 宇宙地图视觉（5颗星球散布），每颗星球显示当前繁荣度状态的视觉
- 点击任一星球进入该星球详情页
- 顶部用户信息：已解锁的星球称号列表 + 领主标识
- 底部：本月全宇宙贡献排行（跨星球总贡献榜）

### 4.2 星球详情页

进入单个星球后的详情页面：

**展示内容：**
- 星球视觉大图（随繁荣度变化）
- 当月繁荣度进度条 + 当前阶段文案
- 当月星球领主展示（头像+称号+贡献值）
- 我的称号等级 + 能量值进度条
- 当月星球贡献排行 Top 10
- 「进入星球」按钮 → 进入该星球的任务列表

### 4.3 称号升级通知

升级时通过站内信 + 弹窗双通道通知：

**弹窗内容：**
- 星球主题升级动画（星球元素+光效）
- 新称号展示
- 新解锁的权益列表

**站内信文案示例：**
- 升级：「恭喜！你在译言星的称号已提升为「文字工匠」，继续建设吧！」
- 领主加冕：「你成为了本月的译言星领主！全星球建设者都能看到你的贡献！」
- 繁荣度里程碑：「好消息！瞭望星在所有建设者的努力下进入了发展期！」
- 衰减预警：「你已 23 天未造访灵感星，7 天后能量值将开始衰减。回来看看吧~」

### 4.4 领主结算与展示

**月度结算流程：**
1. 每月最后一天 23:59 锁定排行
2. 次月 1 日 0:00 生成领主结果
3. 推送通知给新领主 + 星球全体建设者
4. 上月领主的展示位/头像框/称号自动切换

**领主展示位：**
- 星球详情页顶部：领主头像 + 称号 + 月贡献值 + 领主寄语
- 宇宙主页：各星球旁显示当前领主小头像

### 4.5 运营后台

| 功能 | 说明 |
|------|------|
| 星球管理 | 星球名称、主题、视觉资源配置；繁荣度阶段阈值调整 |
| 称号配置 | 各星球各等级的称号名称、图标、能量值阈值 |
| 能量规则 | 按星球配置各行为的能量值，支持活动期间临时加倍 |
| 领主配置 | 领主奖励内容、展示样式、结算时间 |
| 成就配置 | 跨星球成就的条件和奖励 |
| 手动调整 | 支持手动调整指定用户的能量值（含原因记录） |
| 数据看板 | 各星球活跃度、繁荣度趋势、称号分布、领主竞争热度 |

## 五、分期实施建议

### Phase 1：星球框架 + 译言星上线（3-4 周）

**目标：** 先用已有的翻译查错场景验证星球玩法

**范围：**
- Poppo 宇宙主页（宇宙地图视觉，5颗星球但仅译言星可进入，其余"待开发"状态）
- 译言星完整功能：称号体系（T1-T4）、能量值、繁荣度
- 历史数据迁移（已有的翻译查错贡献折算为译言星能量值）
- 称号升级通知
- 星球繁荣度视觉（至少 3 阶段变化）
- 后台基础配置

**不含：** 领主系统、跨星球成就、其余星球

### Phase 2：领主系统 + 第二批星球（3 周）

**目标：** 上线月度竞争机制，开放更多星球

**范围：**
- 星球领主完整功能（月度结算、展示位、领主权益）
- 开放星耀星（站内外宣传、品牌周边等场景接入）
- 开放天秤星（投诉评判场景接入）
- 领主寄语功能
- 称号衰减机制上线

### Phase 3：全星球开放 + 跨星球成就（2-3 周）

**目标：** 宇宙完整，鼓励跨星球探索

**范围：**
- 开放瞭望星（优质主播发掘场景接入）
- 开放灵感星（用户调研、新功能体验场景接入）
- 跨星球成就体系上线
- 全宇宙贡献排行榜
- 贡献卡片分享功能

### Phase 4：精细化运营（持续迭代）

**目标：** 丰富玩法，保持新鲜感

**范围：**
- 星球限时活动（能量加倍周、繁荣度冲刺赛）
- 星球视觉迭代（更多繁荣度阶段、季节性皮肤）
- T4 提案通道上线
- "宇宙霸主"季度实物礼包流程
- 新场景灵活挂载到已有星球或开辟新星球

## 六、关键指标

| 指标 | 定义 | 目标 |
|------|------|------|
| 星球活跃率 | 当月在≥1个星球有贡献的用户 / 全部建设者 | 上线 3 个月后 ≥ 50% |
| 多星球探索率 | 在≥2个星球有贡献的用户占比 | ≥ 25% |
| 繁荣度达成率 | 各星球月度平均达到的繁荣度阶段 | 发展期及以上 |
| 领主竞争热度 | 月度各星球 Top 3 贡献差距 | 前3名差距 < 30%（说明竞争激烈） |
| T2+ 称号渗透率 | 各星球 T2 及以上用户占比 | 40% |
| 建议采纳率 | 被采纳数 / 总提交数 | 维持 ≥ 25% |
| 月活跃建设者 | 当月有≥1次有效提交的建设者数 | 环比增长 ≥ 20%（前 3 个月） |

## 七、风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|----------|
| 领主垄断 | 某些用户每月稳坐领主，其他人放弃竞争 | 连续 3 月领主获"名誉领主"永久标识后不再参与排名；或设置"卫冕加难"机制 |
| 刷量行为 | 为冲领主或称号提交大量低质内容 | 日上限 + 内容去重 + 采纳率低于 10% 触发人工关注 |
| 星球冷热不均 | 部分星球场景少、参与人少，繁荣度始终很低 | 繁荣度阈值按星球独立设置；冷门星球定期开展限时加倍活动 |
| 繁荣度视觉成本 | 5颗星球×5阶段=25套视觉资源，设计成本高 | Phase 1 仅做 3 阶段，后续逐步丰富；可复用基础模型换色/换元素 |
| 称号贬值 | 能量值过易获取，T4 泛滥 | 初期保守设置阈值；观察数据后调整 |
| 衰减引发不满 | 用户觉得辛苦升的称号被降了 | 衰减前 7 天预警；衰减速度温和（2%/周）；不跨级降 |
