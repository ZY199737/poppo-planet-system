## 一、需求背景

### 1.1 现状与问题

当前直播间公屏仅支持文字发言。对于不擅长打字的用户（如部分海外用户、输入法不方便的语种用户），发言门槛较高，影响直播间互动活跃度。同时，语音消息在 IM 场景中已经成熟，但直播间公屏尚未支持。

### 1.2 目标

> **核心目标：** 在直播间公屏新增语音发送能力，支持两种模式：直接发送语音消息（其他用户可点击播放）、语音转文字后以文字形式发送到公屏，降低发言门槛，提升直播间互动率。

### 1.3 成功指标

| 指标 | 当前值 | 目标值 | 统计口径 |
|------|--------|--------|----------|
| 直播间人均发言条数 | 待补充 | +15% | 公屏消息总量 / DAU |
| 语音消息使用率 | 0 | 5%+ | 语音消息数 / 公屏总消息数 |
| 语音转文字使用率 | 0 | 3%+ | 语音转文字消息数 / 公屏总消息数 |

## 二、需求说明

### 2.1 功能点：发送语音消息

#### 产品描述

用户在直播间输入区域切换到语音模式后，长按录音按钮录制语音消息。录制完成后，语音消息以语音气泡形式展示在公屏，其他用户可点击播放收听。

#### 交互规则

- **入口：** 直播间输入框右侧新增「语音/键盘」切换按钮，点击后输入框区域切换为录音按钮
- **录制方式：** 长按录音按钮开始录制，松手发送；上滑取消发送
- **录制时长限制：** 最短 1 秒，最长 60 秒
- **不足 1 秒：** 松手后不发送，toast 提示 "Recording too short"
- **达到 60 秒：** 自动停止录制并发送
- **上滑取消：** 长按后手指上滑超过取消阈值，松手后不发送，toast 提示 "Cancelled"
- **录制中展示：** 显示录音动画 + 当前录制时长 + "Release to send, swipe up to cancel" 提示
- **麦克风权限：** 首次使用时请求麦克风权限；若用户拒绝，点击录音按钮时 toast 提示 "Please enable microphone access in Settings" 并提供跳转系统设置入口
- **RTC 麦克风冲突处理（主播/连麦用户）：** `[客户端]` 主播正在推流或用户正在连麦时，隐藏语音/键盘切换按钮，仅展示文字输入；连麦结束或下麦后恢复语音入口
- **录音时直播间音频处理：** `[客户端]` 录音期间启用系统 AEC（回声消除），过滤扬声器播出的直播间音频，仅采集用户人声；直播间音频正常播放不中断
- **发送失败重试：** `[客户端]` 语音消息上传失败后，语音气泡仍在公屏消息流中展示，气泡右侧显示红色感叹号标记；点击感叹号重新上传发送

#### AI开发规格

```yaml
# 功能标识：FUNC-001

trigger: "用户点击语音切换按钮 AND 麦克风权限已授予"

recording:
  min_duration: 1s
  max_duration: 60s
  format: "AAC / Opus"
  sample_rate: 16000
  channels: 1

behavior:
  on_press: "开始录音，展示录音动画和计时"
  on_release: "duration >= 1s → 停止录音，上传音频文件，发送语音消息到公屏"
  on_release_short: "duration < 1s → 取消，toast 'Recording too short'"
  on_swipe_up: "取消录音，toast 'Cancelled'"
  on_max_duration: "自动停止录音并发送"

display:
  position: "公屏消息流"
  style: "语音气泡：用户头像 + 昵称 + 语音波形条 + 时长标注"
  duration_format: "MM:SS 或 S''"

data_dependencies:
  - field: audio_url
    source: "上传至 CDN 后返回的 URL"
  - field: duration
    source: "客户端录制时长"
```

### 2.2 功能点：语音转文字发送

#### 产品描述

用户在语音录制模式下，可选择将录制的语音通过 ASR（语音识别）转为文字，以文字消息形式发送到公屏。适用于用户想通过语音输入但更希望以文字形式展示的场景。

#### 交互规则

- **入口：** 录音按钮区域提供「语音转文字」模式切换，或在录音完成后弹出选项
- **方式一（推荐）— 独立模式：** 在语音模式下新增「转文字」子模式切换按钮，长按录音后直接将识别结果以文字形式预填到输入框，用户确认后发送
- **识别结果展示：** 识别完成后，文字预填到输入框，用户可编辑修改后发送，也可直接发送
- **识别语言：** 基于用户 App 语言设置自动选择识别语言
- **识别失败：** toast 提示 "Voice recognition failed, please try again"，不发送消息

#### AI开发规格

```yaml
# 功能标识：FUNC-002

trigger: "用户在语音转文字模式下长按录音并松手"

flow:
  1_record: "长按录音，展示录音动画 + 实时/录制完成后识别"
  2_recognize: "音频上传 ASR 服务，返回识别文字"
  3_preview: "识别文字预填到输入框，用户可编辑"
  4_send: "用户确认发送 → 以普通文字消息发送到公屏"

asr:
  language: "auto（基于 App 语言设置）"
  timeout: 10s
  max_audio_duration: 60s

behavior:
  on_recognize_success: "文字预填输入框，光标置末尾"
  on_recognize_fail: "toast 'Voice recognition failed, please try again'"
  on_recognize_empty: "toast 'No speech detected'"
  on_user_edit: "用户可修改识别结果后发送"
  on_user_cancel: "清空输入框，不发送"
```

### 2.3 功能点：语音消息播放

#### 产品描述

公屏上展示的语音消息，其他用户（包括主播和观众）可以点击播放收听。播放时展示播放动画，同一时间只能播放一条语音消息。

#### 交互规则

- **点击播放：** 点击语音气泡播放音频，气泡内波形条播放动画
- **再次点击：** 暂停播放，动画停止
- **播放完毕：** 动画停止，波形条恢复静态
- **互斥播放：** 点击播放新的语音消息时，当前正在播放的语音自动停止
- **听筒/扬声器：** 默认使用扬声器播放（直播间场景）；如果用户贴耳（距离传感器触发），切换为听筒播放
- **与直播音频共存：** 语音消息播放时，直播间音频正常播放，语音消息叠加播放（混音）

#### AI开发规格

```yaml
# 功能标识：FUNC-003

trigger: "用户点击公屏语音消息气泡"

playback:
  output: "speaker（默认），proximity_sensor → earpiece"
  mix_with_live_audio: true
  concurrent: false  # 同一时间只播放一条

behavior:
  on_tap_playing: "暂停播放，动画停止"
  on_tap_paused: "继续播放，动画恢复"
  on_tap_new: "停止当前，播放新的"
  on_playback_end: "动画停止，波形条恢复静态"
  on_proximity_near: "切换听筒播放"
  on_proximity_far: "切换扬声器播放"

display:
  playing_animation: "波形条左到右流动动画"
  paused_state: "波形条静态，显示播放进度"
```

## 三、数据与接口

### 3.1 核心数据结构

```typescript
interface VoiceMessage {
  message_id: string;
  room_id: string;                  // 直播间 ID
  sender_id: string;                // 发送者用户 ID
  type: "voice";                    // 消息类型
  audio_url: string;                // 音频文件 CDN 地址
  duration: number;                 // 音频时长，单位秒，精度 0.1s
  file_size: number;                // 文件大小，单位字节
  format: "aac" | "opus";          // 音频编码格式
  created_at: string;               // ISO 8601 时间戳
}
```

### 3.2 接口定义

```yaml
api:
  id: API-001
  method: POST
  path: /api/v2/live/room/{room_id}/voice-message/upload
  auth: required
  description: "上传语音文件并发送语音消息到直播间公屏"

  request:
    body:
      file: { type: binary, required: true, description: "音频文件，AAC/Opus 格式" }
      duration: { type: float, required: true, description: "音频时长，单位秒" }

  response:
    success: { status: 200, body: { code: 0, data: { message_id: "string", audio_url: "string" } } }
    errors:
      - { status: 400, code: 30001, message: "音频时长不合法", client_action: "toast 提示" }
      - { status: 400, code: 30002, message: "音频文件过大", client_action: "toast 提示 'File too large'" }
      - { status: 403, code: 30003, message: "用户被禁言", client_action: "toast 提示 'You are muted'" }
      - { status: 403, code: 30004, message: "直播间不支持语音消息", client_action: "toast 提示并隐藏语音入口" }
      - { status: 429, code: 30005, message: "发送频率过高", client_action: "toast 提示 'Please wait before sending another voice message'" }
      - { status: 401, code: 10001, message: "未登录", client_action: "跳转登录页" }
```


| ID | 场景 | 条件 | 期望行为 | 必要性 |
|----|------|------|----------|--------|
| EC-001 | 麦克风权限未授予 | 用户首次点击语音按钮，系统弹出权限请求，用户拒绝 | toast "Please enable microphone access in Settings"，提供跳转系统设置入口 | **必须** |
| EC-002 | 录制时长不足 | 用户按下后快速松手，录制时长 < 1 秒 | 不发送消息，toast "Recording too short" | **必须** |

| EC-005 | ASR 识别失败 | 语音转文字服务返回错误或超时（10s） | toast "Voice recognition failed, please try again"，不发送消息 | **必须** |

| EC-009 | 语音播放中退出直播间 | 正在播放语音消息时用户退出直播间 | 停止播放，释放音频资源 | **必须** |
| EC-010 | 网络弱环境播放 | 点击播放语音但音频加载缓慢 | 展示加载动画，超时 10s 后 toast "Loading failed, please try again" | **必须** |
| EC-011 | 重复点击发送 | 用户快速连续录制发送语音 | 客户端防抖，前一条上传完成前不允许开始新的录制；toast "Please wait" | **必须** |
| EC-012 | 音频文件过大 | 音频文件超过服务端限制（建议上限 2MB） | toast "File too large"，不发送 | **必须** |
| EC-013 | 主播/连麦用户录音冲突 | 主播正在推流或用户正在连麦时 | 隐藏语音/键盘切换按钮，仅展示文字输入；连麦结束或下麦后恢复语音入口 | **必须** |
| EC-014 | 录音时直播音频回声 | 用户录音时直播间正在外放主播/嘉宾音频 | 启用系统 AEC 回声消除过滤扬声器音频，仅采集用户人声；直播间音频不中断播放 | **必须** |

## 七、技术备注

- **音频格式：** 推荐 AAC（iOS 原生支持好）或 Opus（压缩率高、适合弱网），双端需统一编解码格式
- **文件大小控制：** 60s 音频在 16kHz 单声道 AAC 编码下约 500KB-1MB，建议上限 2MB
- **CDN 缓存：** 语音文件上传 CDN 后设置合理过期时间（建议 7 天），过期后公屏历史消息中语音不可播放
- **平台差异：** iOS 使用 AVAudioRecorder/AVAudioPlayer；Android 使用 MediaRecorder/MediaPlayer 或 AudioRecord/AudioTrack
- **距离传感器：** iOS/Android 均需监听距离传感器事件切换听筒/扬声器
- **ASR 服务：** 语音识别服务选型待定（Google Speech-to-Text / 自建服务 / 第三方），需支持多语言
